# 自动换料

Ace Pro Control Center 把“设备可以连接”“设备允许物理动作”和“自动换料已经就绪”分成三个独立条件。仅把模式改为 `automatic` 不会绕过任何安全检查。

> **严重警告：** 自动换料会移动打印头、驱动挤出机、送料、回料并执行切刀。错误的坐标、方向、温度、距离或传感器状态可能造成撞机、撞打印件、误切、堵头、磨料或挤出机损坏。所有动作必须按本机结构重新验证，禁止照搬其他打印机的坐标和宏。

## `manual` 与 `automatic`

```ini
[ace]
toolchange_mode: manual
```

### `manual`：默认安全模式

在 `manual` 模式下：

- ACE 可以连接并读取设备、槽位、RFID、库存、传感器和编码器状态。
- `physical_actions_enabled: False` 的设备不能执行送料、回料、烘干或辅助送料。
- ACE1 经本机验证并设置 `physical_actions_enabled: True` 后，可以单独使用已支持的手动动作和辅助送料。
- 自动换料、自动切刀和无限续料不启动。
- `T0-T15` 与 `TR` 每次都会被提示并忽略，打印不暂停、不拒绝，也不会改变当前工具或路径状态。

典型提示如下：

```text
ACE 自动换料未配置，已忽略 T0。当前无法进行多色打印，仅可使用已启用的 ACE 内置辅助送料。
```

这里的“可使用辅助送料”仍受单设备物理动作门禁限制。门禁为 `False` 时，辅助送料也不可用。

### `automatic`：请求启用自动换料

```ini
[ace]
toolchange_mode: automatic
```

`automatic` 只表示用户要求使用自动换料。驱动仍会检查：

1. 至少一台已启用 ACE1 允许物理动作。
2. 七个必用宏都已经绑定并在 Klipper 中注册。
3. 共享编码器不在校准中；若 `encoder_mode: protect`，编码器必须可用且已校准，并且挤出机接管段的保证运动距离不短于 `encoder_detection_length`。
4. 上方传感器状态提供器存在且可读取，上方传感器已配置，入口到喷嘴距离已标定，`upper_sensor_feed_timeout` 位于 `1..120` 秒；默认旁路时下方不是就绪条件，显式关闭旁路后必须通过下方闭环预检。
5. 多 ACE 时总五通传感器已配置。
6. 多 ACE 的每台动作型 ACE 已校准本设备分支回退距离。
7. 共享路径状态为 `empty` 或 `nozzle`，不是 `unknown`。
8. 执行动作时，目标设备在线、目标槽位有料且能力可用。

任一条件不满足时，Klipper 仍可启动，状态读取仍可使用，但自动换料显示“尚未就绪”，`T` 指令继续只提示并忽略。不要删除检查项或关闭切刀要求来消除提示。

## V3 必须使用切刀

V3 不执行耗材尖端成型。旧耗材若不切断，变形端部可能卡在挤出机、五通或 Bowden 管内，因此自动换料必须具备经过本机真机验证的切刀动作：

```ini
[ace]
require_cut_hook: True
```

必须保持 `require_cut_hook: True`。切刀宏需要自行适配本机切刀机构、运动范围和归零条件。驱动会在切断旧料前检查目标槽是否可用；目标槽为空或路径状态不可信时，不应先切断当前耗材。

## 七个必用宏

自动换料固定使用以下七个入口：

| 宏名称 | 作用 | 默认模板状态 |
| --- | --- | --- |
| `_ace_prepare_toolchange` | 保存运动状态、抬升、停车并确认换料条件 | 物理实现整段注释，等待本机适配 |
| `_ace_cut_filament` | 移动到切刀并切断旧耗材 | 物理实现整段注释，等待本机适配 |
| `_ace_load_filament_to_toolhead` | 把装载请求交给 V3 路径控制器 | 活动的驱动桥接宏 |
| `_ace_unload_filament_from_toolhead` | 把卸载请求交给 V3 路径控制器 | 活动的驱动桥接宏 |
| `_ace_wipe_nozzle` | 调用本机经过验证的喷嘴清理流程 | 物理实现整段注释，等待本机适配 |
| `_ace_restore_after_toolchange` | 恢复高度、运动状态和打印位置 | 物理实现整段注释，等待本机适配 |
| `_ace_pause_on_toolchange_error` | 报告失败，并仅在活动打印中请求暂停 | 活动的错误处理宏 |

名称绑定位于 `ace.cfg`：

```ini
[ace_machine]
pre_toolchange_macro: _ace_prepare_toolchange
cut_macro: _ace_cut_filament
load_to_toolhead_macro: _ace_load_filament_to_toolhead
unload_from_toolhead_macro: _ace_unload_filament_from_toolhead
wipe_nozzle_macro: _ace_wipe_nozzle
post_toolchange_macro: _ace_restore_after_toolchange
pause_on_error_macro: _ace_pause_on_toolchange_error
```

绑定和实现不是一回事：

- `[ace_machine]` 告诉驱动要调用哪个名字。
- `[gcode_macro ...]` 才是实际执行内容。
- 默认启用名称绑定不会自动启用注释样板，也不会执行样板中的任何坐标。
- 不得用空宏、仅注释宏或无意义响应来伪装“已实现”。

`_ace_load_filament_to_toolhead` 和 `_ace_unload_filament_from_toolhead` 只是受控入口。实时传感器循环、挤出机分段运动、ACE 协同回抽和停止条件由 Python 路径控制器完成，不要把它们改写为普通 Jinja 循环，也不要作为日常手动送料命令调用。

### 宏参数

| 宏 | 驱动传入参数 |
| --- | --- |
| 前处理、擦嘴、后处理、故障暂停 | `FROM`、`TO` |
| 切刀、送料、回料 | `TOOL`、`DEVICE`、`SLOT` |

自定义宏应允许驱动传入这些参数。不要依赖某一切片器私有变量，也不要在宏中重新定义 `T0-T15` 或 `TR`。

## 宏的本机适配要求

### 换料前处理

至少应处理：

- 确认需要的轴已经归零。
- 保存当前 G-code 状态和打印位置。
- 只在 Z 行程允许时抬升，并记录实际抬升量。
- 移动到本机安全停车位置。
- 按材料和挤出机能力确认可执行卸载，不使用通用固定温度。

验证顺序：先在无打印、无模型环境中检查归零和行程；再以低速验证抬升与停车；随后验证状态保存；最后与后处理成对验证恢复。任何一步出现越界、碰撞风险或状态丢失，都保持宏禁用。

### 切刀

至少应处理：

- 确认切刀所需轴已经归零。
- 使用本机切刀的真实接近点、切入方向、行程和速度。
- 保证打印件、探针、刷子、机架和线缆不在运动路径内。
- 切刀只负责切断，不在宏中重复执行 V3 已管理的长距离回抽。

验证顺序：先断料并以低速验证空行程；再用短段废料验证一次切断；确认无卡滞后验证完整往复；最后才允许由换料事务调用。第一次验证不得在打印中进行。

### 擦嘴

擦嘴宏应调用本机已经验证的清理动作，并明确它是否需要归零、加热、探针收回或特定停车位置。

验证顺序：先确认清理机构位置和各轴范围；无打印时低速验证空行程；再在安全温度下验证实际清理；最后检查它与前处理、后处理的状态保存没有冲突。

### 换料后处理

后处理必须与前处理配套，恢复实际抬升量和保存的运动状态。不得假定固定 Z 高度，也不得在前处理失败后盲目下降。

验证顺序：先验证“前处理 -> 后处理”无料往返；检查恢复位置和坐标模式；再验证暂停状态；最后才在短测试打印中验证。错误的恢复可能撞击打印件。

### 故障暂停

故障宏不应移动、切料或继续送料。它应给出明确提示，并只在 `print_stats` 为活动打印时请求一次暂停。

验证顺序：先在待机状态调用并确认不会暂停或运动；再用受控测试确认活动打印只暂停一次；不得通过制造真实堵料作为第一次测试。

## 控制权交接与分段动作

### ACE 固件负责的内部预装载

用户把耗材插入 ACE 槽位入口后，ACE 自动卷入耗材并停在设备内部的预装载/停放位置。这一段属于 ACE 固件自身行为：

- V3 不发起槽口卷入动作。
- V3 不配置、测量或补偿槽口到内部停放点的长度。
- V3 的外部装载流程从 ACE 已经完成内部预装载的停放点开始。

若 ACE 没有自行完成内部预装载，应先按设备本身的装料流程排查，不能通过增加 V3 参考量替代固件预装载。

### ACE 不是定距送料轴

ACE Pro 使用直流送料电机。耗材摩擦、线径、卷盘阻力、压轮压力和 PTFE 阻力都会改变相同送料时间对应的实际距离。因此 `toolchange_load_length`、`feed_slip_compensation_length` 等距离只是发送给 ACE 固件的参考量或分段请求量：

- 不代表耗材真实移动了相同毫米数。
- 不能相加后当作耗材位置或成功终点。
- 不能因为参考量执行完毕就把路径标记为已装载。

### 装载顺序

```text
ACE 内部预装载/停放点
  │  ACE 受限送料；编码器可检查是否有进展
  ▼
上方传感器稳定触发（唯一成功终点）
  │  停止 ACE，控制权交给挤出机步进电机
  ▼
挤出机按入口到喷嘴的本机标定距离送料
  │  编码器可验证真实跟随
  ▼
喷嘴目标位置
```

ACE 阶段必须同时满足以下规则：

1. 上方传感器稳定触发是唯一成功终点，触发后立即停止 ACE。
2. 驱动把送料拆成最长约 `2` 秒的受限窗口。每个窗口都重新读取上方传感器并检查编码器进展；`monitor` 无进展只提示，`protect` 无进展中止。
3. 主参考量和低速补偿参考量耗尽后，不会据此判定失败；驱动继续以补偿速度分段寻找上方传感器。固件提前报告窗口完成时，仍保留不超过总截止时间的传感器宽限。
4. `upper_sensor_feed_timeout` 默认 `30` 秒、范围 `1..120` 秒。达到时间仍未触发上方传感器时无条件停止，即使编码器仍有脉冲也不能继续；截止后的迟到信号不算成功。
5. 读取传感器或等待动作发生异常时必须停止 ACE。没有编码器时仍可依靠上方传感器和总超时工作；超时只能报告“未到达上方传感器”，不能仅凭这一结果断言具体是堵料、空槽还是传感器故障。

上方传感器触发后，挤出机执行“上方交接点到喷嘴目标位置”的标定距离。`toolhead_sensor_bypass_load_length` 只表示这一挤出机步进距离；模板 `25 mm` 是未校准样板，必须按本机重复测量并把 `toolhead_sensor_bypass_calibrated` 改为 `True`，不能当作 ACE 的真实送料距离，也不能仅凭非零样板进入自动换料就绪。编码器在挤出机段无脉冲时，可提示耗材可能未进入挤出齿轮、齿轮未咬料或发生打滑；`protect` 必须停止并禁止标记已装载。

### 下方传感器是可选观测点

下方传感器可以不安装。默认 `toolhead_sensor_bypass: True` 时，引脚可留空；填写引脚后仅监测原始状态，不参与必要结论。用户确认下方传感器稳定后可显式设为 `False` 恢复下方闭环，此时必须通过对应触发、释放和距离预检。

### 卸载顺序

```text
喷嘴/挤出机内旧料
  │  切刀完成后由挤出机受限回抽；编码器可验证后退
  ▼
上方传感器稳定释放
  │  控制权交给 ACE 回抽
  ▼
总五通释放 -> 当前一级五通释放/受限盲回退 -> 停车余量
```

默认旁路时，卸载由上方传感器释放完成交接；显式关闭旁路后，下方传感器恢复参与闭环装卸。ACE 回抽仍依靠总五通、一级五通或已校准受限盲回退停车。

### 本机验证顺序

1. 保持 `toolchange_mode: manual`，确认上方传感器与当前拓扑所需五通传感器的方向、去抖和状态读取正确；下方传感器只验证显示。
2. 在打印机待机、低速且可立即停止的条件下，验证上方传感器稳定触发会立即停止 ACE。
3. 验证达到最大送料时间且上方未触发时会停止；不要用堵死喷嘴或强行夹料制造故障。
4. 让耗材停在上方传感器刚稳定触发的位置，用挤出机小步长送到喷嘴目标位置，重复至少三次后填写标定距离。
5. 如安装编码器，先用 `monitor` 分别观察 ACE 寻位段和挤出机接管段，再验证 `protect`。
6. 验证卸载时挤出机先回抽到上方释放，之后 ACE 才清空总五通和当前一级分支。
7. 各阶段均通过后，才在待机状态执行一次完整装卸，最后进入自动换料测试。

## 路径动作验证顺序

在启用自动换料前，按以下顺序完成一次完整的本机验收：

1. **静态配置检查**：保持 `manual`，所有设备 `physical_actions_enabled: False`；确认七个绑定名称无拼写错误，Klipper 可正常启动。
2. **传感器检查**：手动插入和抽出耗材，确认上方、总五通及多 ACE 一级五通的有料/无料状态正确；下方传感器若安装，只核对原始显示。
3. **机器宏检查**：按上一节分别验证前处理、切刀、擦嘴、后处理和故障宏；测试期间不执行 ACE 长距离动作。
4. **路径距离检查**：测量共享 Bowden、传感器到喷嘴以及五通停放距离；模板数值不得直接使用。
5. **单设备短动作**：只给一台已确认的 ACE1 设置 `physical_actions_enabled: True`，使用低速、短距离手动送料和回料验证方向与停止。
6. **完整手动装卸**：在待机状态验证从空路径装载到喷嘴、再完全卸载；确认路径最终分别为 `nozzle` 和 `empty`。
7. **错误停止检查**：断开动作前先设计安全退出方式，确认传感器未触发、目标槽为空或路径未知时动作会停止并提示。
8. **编码器观察**：如安装编码器，先保持 `encoder_mode: monitor`；确认脉冲和跟随结果可信后才考虑 `protect`。
9. **多 ACE 分支检查**：逐台验证一级分支退出和总五通释放；多机跨设备换料见 [多 ACE](Multi-ACE)。
10. **最后切换模式**：所有项目通过后才设置 `toolchange_mode: automatic`，重启并检查状态中的 `toolchange_ready`。

手动测试命令中的距离和速度必须替换为本机选择的低风险数值：

```gcode
ACE_FEED TOOL=T0 LENGTH=<短测试距离> SPEED=<低测试速度>
ACE_RETRACT TOOL=T0 LENGTH=<短测试距离> SPEED=<低测试速度>
```

不要把带尖括号的占位示例直接发送给 Klipper。

## 自动模式首次验收

1. 打印机待机、热端和运动系统处于本机宏要求的安全状态。
2. 执行 `ACE_GET_STATUS`，确认 `toolchange_mode` 为 `automatic`、`toolchange_ready` 为真，且没有未知路径或编码器故障。
3. 先在无打印状态从空路径装载一个工具，再卸载到空路径。
4. 在同一 ACE 内验证两个槽位之间的换料。
5. 多 ACE 用户完成所有分支清空验证后，才测试跨设备换料。
6. 使用废料完成短测试打印，观察前处理、切刀、装载、擦嘴和恢复顺序。
7. 最后验证一个不会损伤机器的受控失败场景，确认只暂停一次且路径转为需要人工检查的状态。

自动模式可用后，切片器展开出的 `T0-T15` 会进入 V3 工具选择流程；`TR` 表示卸载当前工具。实际可换工具范围由安装的设备数量决定：单 ACE 为 `T0-T3`，四台 ACE 才达到 `T0-T15`。

## 不要这样绕过预检

- 不要把 `require_cut_hook` 改为 `False`。
- 不要删除七个名称绑定。
- 不要创建空宏只为让名称存在。
- 不要把注释样板的坐标直接取消注释。
- 不要在切刀宏里加入固定长距离 `FORCE_MOVE`，卸载由 V3 路径控制器负责。
- 不要在路径状态为 `unknown` 时直接开始下一次换料。
- 不要让两台 ACE 同时启用辅助送料；共享路径同一时刻只能有一个动作所有者。
- 不要把 ACE 固件参考距离当作真实位移，也不要照搬入口到喷嘴的模板距离；挤出机标定值为 `0` 或无效时，自动换料必须保持未就绪。

## 当前验证边界

- 单 ACE 配置链、状态读取、受限窗口送料、路径控制、编码器保护和安全预检已完成本地代码与模拟验证，当前进入目标打印机验收阶段。
- 多 ACE 两级五通已完成配置解析、状态机和模拟测试，但跨设备物理送料、回抽和分支清空尚未完成真机验收。
- ACE2 当前为协议模拟与只读状态能力，不能参与物理自动换料。
- 发布模板不包含任何通用可用的停车、切刀或擦嘴坐标；这些能力必须由用户在自己的打印机上完成验证。
- 本轮软件验证通过不代表可以直接正式打印。上方交接、挤出机标定距离、编码器真实脉冲、完整装卸和故障停止仍需在目标机逐项验收。
