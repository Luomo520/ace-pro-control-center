# Ace Pro Control Center | ACE Pro 管理中心

Ace Pro Control Center 是面向通用 Klipper 设备的 Anycubic ACE 第三代驱动，最多支持 4 台 ACE 共用一个打印头和一条公共耗材路径。设备顺序固定映射到 `T0-T15`，不会因 USB 重枚举而改变工具号。

正式版本名为 `V2.5ahpha`。配置中的 `driver_version: 3` 仅表示第三代内部配置协议。第一次安装建议按照[从零安装到首次打印](Beginner-Tutorial)逐步操作；只想先完成无动作安装时可阅读[快速开始](Quick-Start)。不要在未核对机器坐标、切刀和耗材路径时启用物理动作。

## 使用前必须理解的状态

| 状态 | 含义 | 不代表什么 |
| --- | --- | --- |
| 已配置 | 配置文件中已有设备、引脚、距离或宏绑定，且格式可被驱动读取 | 不代表该功能已经允许执行 |
| 已启用 | 运行模式和安全开关允许该功能进入预检或执行流程 | 不代表动作适合当前机器，也不代表已真机验收 |
| 已真机验证 | 已在明确的机器、拓扑和测试条件下实际执行并记录结果 | 不自动覆盖其他机器、其他 ACE 型号或多设备拓扑 |

这三个状态不能互相替代。例如，填写了切刀宏只表示“已配置”；同时启用自动模式和设备物理动作门禁后才可能“已启用”；在本机逐项完成切刀位置、方向和碰撞检查后，才能称为该机器上的“已真机验证”。

## 当前能力边界

| 功能 | 当前状态 |
| --- | --- |
| ACE1 连接、四槽状态和只读信息 | 已在单台 ACE1 上部署验证 |
| Fluidd 卡片、完整页面和独立备用页 | 已完成单 ACE 只读场景部署验证 |
| ACE1 送料、回抽、切刀和自动换料 | 已实现驱动与安全门禁，尚未完成全部真机物理动作验收 |
| 多 ACE 配置、工具映射、界面和两级五通状态机 | 已配置并通过本地模拟，尚未完成多 ACE 真机物理动作验收 |
| ACE2 | 已实现协议模拟和只读路径；没有实体 ACE2 真机验证，物理动作强制拒绝 |
| 共享编码器 | 支持配置、状态、校准和监测；必须在具体机器上单独校准和验收 |

文档中出现“支持”时，应结合上表判断它是配置能力、运行能力还是已完成真机验收的能力。

## 默认安全状态

全新安装使用以下默认值：

```ini
[ace]
toolchange_mode: manual
```

```ini
[ace_device ace0]
physical_actions_enabled: False
```

这两个开关彼此独立：

- `toolchange_mode: manual` 不启动自动换料事务。
- `physical_actions_enabled: False` 拒绝该设备的送料、回抽、烘干、辅助送料等物理动作。
- 安装完成、设备在线或界面显示正常，都不会自动改变这两个值。

保持默认值时，可以先检查设备连接、槽位状态、RFID 显示、传感器状态和 Fluidd 页面，不会因为安装器而执行送料、回抽、切刀、烘干或换料。

## 支持的拓扑

- 1 台 ACE：`T0-T3`，四槽直接进入 1 个总五通，不使用一级五通。
- 2 台 ACE：`T0-T7`，每台使用 1 个一级五通，再进入 1 个总五通。
- 3 台 ACE：`T0-T11`，共 3 个一级五通和 1 个总五通。
- 4 台 ACE：`T0-T15`，共 4 个一级五通和 1 个总五通。

ACE 内置缓冲和张力调节属于设备内部机构，V3 不提供独立缓冲器节点，也不把它套用为 Happy Hare/AFC 的外置缓冲传感器。多 ACE 物理路径尚未完成真机验收，配置完成不等于可以直接执行跨设备自动换料。

## 推荐开始顺序

1. 第一次使用时按[从零安装到首次打印](Beginner-Tutorial)准备备份、运行兼容性检查和 `--dry-run`。
2. 安装后保持 `manual` 和 `physical_actions_enabled: False`，先完成只读验收。
3. 按[配置说明](Configuration)填写真实引脚和路径参数。
4. 阅读[安全与限制](Safety-and-Limitations)，再逐项验证机器宏和物理动作。
5. 只有全部自动换料预检条件满足后，才按照[自动换料](Automatic-Toolchange)启用自动模式。

## 重要提醒

自动换料未配置或未就绪时，驱动会逐条提示并忽略 `T0-T15` 和 `TR`，不会暂停打印。这样可以让单色打印继续，但多色切片会以错误颜色继续打印。确认自动换料已经达到“已启用且已在本机验证”之前，不要使用多色打印文件。

当前编码器校准默认采用 `150 mm x 3` 分段测量，段间偏差按 `5%/10%` 门槛处理；运行时仍使用短检测窗口。安装器在写入前保留持久快照并生成恢复脚本。每次发布是否满足这些契约，仍以[开发与测试](Development-and-Testing)列出的自动化校验结果为准，不能仅凭文档或模拟器判定。
