# 安全与限制

Ace Pro Control Center 第三代驱动面向不同结构的通用 Klipper 打印机。驱动无法自动判断本机的切刀位置、工具头运动范围、归零条件、喷嘴温度、耗材路径和传感器接线。任何通用示例都不能直接作为本机校准结果。

> **危险：** 未经验证的切刀、工具头移动、挤出机送料或回抽可能造成撞机、夹伤、切刀损坏、挤出机堵塞、热端磨料和耗材路径破损。启用物理动作前，必须逐项核对并在打印机待机状态下完成本机验收。

## 状态术语

- **已配置**：参数、引脚或宏已写入并能被读取。
- **已启用**：运行模式和安全门禁允许功能执行。
- **已真机验证**：已在明确的机器、拓扑和测试条件下实际执行并记录结果。

“已配置”不等于“已启用”，“已启用”也不等于“已真机验证”。界面显示设备在线只证明通信状态，不证明送料、回抽、切刀或自动换料可安全运行。

## 默认安全门禁

全新安装默认：

```ini
[ace]
toolchange_mode: manual
```

```ini
[ace_device ace0]
physical_actions_enabled: False
```

两个门禁作用不同：

- `toolchange_mode: manual` 禁止自动换料事务。
- `physical_actions_enabled: False` 拒绝该设备的物理动作。
- 自动模式不会绕过设备门禁；设备门禁打开也不会自动启用自动换料。
- 缺少机器宏、传感器或路径参数时，Klipper 仍应启动并提供只读状态，自动换料保持未启用或未就绪。

不要为了消除“未就绪”提示直接打开两个开关。提示代表预检条件没有满足，应修正原因，而不是绕过门禁。

## 当前真机验收范围

| 项目 | 状态 | 限制 |
| --- | --- | --- |
| 单台 ACE1 连接、四槽状态和前端只读显示 | 已真机验证 | 仅代表已测试的单 ACE1 环境 |
| ACE1 送料、回抽、切刀和自动换料 | 已配置并具备门禁 | 尚未完成全部真机物理动作验收 |
| 多 ACE 配置、两级五通和跨设备状态机 | 已实现并本地模拟 | 尚未完成多 ACE 物理路径验收 |
| ACE2 只读协议 | 已实现并协议模拟 | 没有实体 ACE2 真机验证 |
| ACE2 物理动作 | 未启用 | 当前版本在管理层和协议层强制拒绝 |
| 共享编码器 | 可配置 | 每台机器必须单独完成脉冲确认、校准和监测验收 |
| 上方交接与可选下方传感器 | 设计契约已确定 | 最大送料时间、挤出机标定距离、编码器双阶段验证及完整装卸尚需完成真机验收 |

不得把 ACE1 的结果外推到 ACE2，也不得把单 ACE 结果外推到多 ACE。

## 自动换料的必要条件

V3 不执行尖端成型。自动换料退出旧料时必须使用切刀，不能通过关闭切刀要求来绕过预检。

自动换料至少需要以下七个宏全部存在并符合本机实际结构：

- `_ace_prepare_toolchange`
- `_ace_cut_filament`
- `_ace_load_filament_to_toolhead`
- `_ace_unload_filament_from_toolhead`
- `_ace_wipe_nozzle`
- `_ace_restore_after_toolchange`
- `_ace_pause_on_toolchange_error`

宏名称绑定默认存在，不表示宏内的物理动作已经配置。尤其是换料前处理、切刀、擦嘴和换料后处理，其样板动作可能仍被注释。取消注释前必须核对：

- 坐标使用绝对还是相对模式。
- 所需轴是否已经归零。
- 所有目标坐标是否在本机可达范围内。
- 工具头、探针、热床、料架和机壳之间是否有足够间隙。
- 切刀进入方向、行程、速度和复位方向是否正确。
- 喷嘴和挤出机是否达到所用耗材允许的动作温度。
- 挤出与回抽距离是否低于本机 Klipper 限制并适合实际路径。
- 故障宏能否可靠暂停并保留可恢复现场。

自动换料始终要求上方传感器可读取、入口到喷嘴距离已标定、`upper_sensor_feed_timeout` 有效且路径可恢复。下方传感器不是通用必装项：默认旁路时不是就绪条件，用户显式关闭旁路后必须通过下方闭环预检。

## 切刀与工具头移动

切刀和擦嘴宏是最高风险的机器动作：

1. 不要照搬其他打印机、公开视频或 Wiki 示例中的坐标。
2. 不要在轴未归零、坐标模式未知或打印进行中测试。
3. 不要一次启用整套自动换料后直接用打印任务验证。
4. 应逐个宏、逐段动作验证方向、限位、速度和安全间隙。
5. 每次修改坐标、切刀结构、工具头、探针或固件运动限制后，都应重新验收。

切刀宏能够被调用只表示“已启用”；只有在当前机器上完成动作检查并记录结果，才是“已真机验证”。

## 传感器限制

- 传感器引脚留空表示未启用，不应导致 Klipper 启动失败。
- 上方传感器负责 ACE/挤出机交接，总五通与多 ACE 一级五通负责回抽停车；下方传感器只作可选观测，不能替代任何权威停止点。
- 传感器电平反相、上拉方式和触发状态必须按真实接线验证。
- 仅看到界面状态变化不够，还要确认状态与耗材实际位置一致。
- 上方或五通等权威传感器故障、状态矛盾时，物理换料必须失败关闭；下方传感器的缺失或原始跳变只用于观察。

单 ACE 只有总五通，不使用一级五通。一级五通只属于 2 至 4 台 ACE 的多设备拓扑。

## ACE 与挤出机控制边界

ACE Pro 使用直流送料电机，不得将任何固件命令距离或累计参考量解释为真实耗材位置。ACE 送料只有在上方传感器稳定触发时才成功：

- 编码器用于判断是否仍有实际进展，但不能代替上方传感器宣告到位。
- 最大送料时间是最终硬保护；达到时间必须停止，即使编码器仍有脉冲也不能继续。
- 上方触发后必须停止 ACE，再由挤出机步进电机执行入口到喷嘴的本机标定距离。
- 入口到喷嘴距离必须在待机状态低速、小步长测量并至少重复三次；模板 `25 mm` 只是未校准样板。完成实测并把 `toolhead_sensor_bypass_calibrated` 改为 `True` 前，即使数值为 `25` 也不得启用自动换料。
- 编码器在挤出机段可发现“已命令运动但耗材未跟随”；`monitor` 只提示，`protect` 中止并禁止标记已装载。

下方传感器可以不安装。`toolhead_sensor_bypass: True` 时填写引脚也仅监测；用户验证稳定后可显式设为 `False` 恢复下方闭环。默认旁路卸载到上方传感器释放后交给 ACE；闭环模式按下方传感器配置参与装卸。

ACE 内置缓冲结构属于设备内部机构，不能套用为 Happy Hare/AFC 的外置缓冲、压缩或张力传感器，也不能成为虚拟归位点。

## 多 ACE 路径限制

多 ACE 共用一条下游路径。任何时刻只能有一个设备占用公共路径，跨设备换料必须先确认旧料退出当前一级分支并释放总五通，之后才能允许另一台 ACE 送料。

多 ACE 自动换料必须具备：

- 可读取的总五通传感器。
- 每台可执行动作的 ACE 都有一级五通传感器，或具有经过本机实测的受限盲回退距离。
- 未安装一级传感器时，为对应设备填写并验证 `aceN_hub_retract_length` 与 `aceN_hub_clear_move_length`。
- 清晰、无交叉挤压的物理管路和唯一公共路径占用规则。

模板距离不是校准值。一级传感器 pin 留空且距离未校准时，Klipper 可以启动，但多 ACE 自动换料必须保持未就绪。多 ACE 两级路径尚未完成真机物理动作验收，当前不应作为已经验收的生产功能宣传或使用。

## 共享编码器限制

共享编码器安装在总五通之后、上方传感器之前，用于判断耗材是否发生移动。它不能：

- 判断路径中是否有耗材。
- 替代上方、总五通或一级五通传感器；下方传感器本身就是独立的可选观测点。
- 无上限自动追加送料、把 ACE 参考量当作真实欠料距离或自动恢复故障。
- 在未校准时提供可靠的距离判断。

新配置应保持 `encoder_mode: off` 和 `encoder_print_mode: off`。完成脉冲变化确认及默认 `150 mm x 3` 分段校准后，先使用 `monitor` 观察；三段最大偏差 `<=5%` 可通过，`>5%` 且 `<=10%` 必须警告确认，`>10%` 或任一段脉冲不足必须拒绝保存。校准段长不能替代运行时短检测窗口。只有误报、漏报和故障处理均完成本机验收后，才考虑 `protect` 或打印 `pause`。编码器接口可用属于“已配置”，校准成功属于“已校准”，保护策略经过真实故障测试后才属于“已真机验证”。

## 手动模式与 T 指令

自动换料未配置或未就绪时，`T0-T15` 和 `TR` 会：

- 每条都显示提示。
- 被安全忽略。
- 不获取公共路径锁，不调用机器宏，也不改变当前工具状态。
- 不拒绝、不暂停当前打印。

每一条指令都必须显示包含实际工具号的中文提示，例如：“ACE 自动换料未配置，已忽略 T0。当前无法进行多色打印，仅可使用已启用的 ACE 内置辅助送料。”提示不去重。ACE 完全未配置时也采用同一原则：只允许只读管理和已经授权的内置辅助送料，不能暗示手动送料、回料或自动换料已经可用。

这一行为避免误写的 T 指令中断单色任务，但无法阻止多色文件继续以错误颜色打印。开始多色打印前，应确认自动换料已经就绪并在当前机器上完成相关物理动作验收。

## ACE 内置辅助送料

辅助送料独立于自动换料，可以在手动模式下使用，但仍属于物理动作：

- 对应设备必须已开启 `physical_actions_enabled`。
- 打印中启用必须显式确认，例如 `ACE_ENABLE_FEED_ASSIST TOOL=T0 CONFIRM=1`。
- 单打印头全局同时只能有一个辅助送料槽位。
- 自动换料装载前会先停用活动辅助送料；停用失败时不得继续换料。
- 辅助送料不能替代自动换料，也不能保证多色文件使用正确耗材。

在实际耗材路径、张力和停止条件尚未验证时，不要仅因单 ACE 内置缓冲机构存在就启用辅助送料。

## 打印期间的限制

- 不在打印中重启 Klipper、Moonraker 或 Fluidd 服务。
- 不在打印中测试切刀、手动送料、手动回抽、编码器校准或路径距离。
- 安装、升级和卸载前先确认打印机处于待机状态。
- 非幂等物理命令不会自动重试；通信超时后先检查实际耗材位置，不要立即重复动作。
- 状态未知、传感器矛盾、设备掉线或公共路径占用不明时，停止物理动作并人工检查。

## 第一次物理动作前检查表

- [ ] 已保存可恢复的 Klipper、Moonraker、Fluidd 和宏配置备份。
- [ ] 打印机处于待机状态，运动区域内没有工具或障碍物。
- [ ] ACE 型号、数量、稳定串口、UID 和 `T` 映射均已核对。
- [ ] 上方和五通传感器引脚、电平及实际耗材位置一致；可选下方传感器若安装，原始显示正确。
- [ ] ACE 最大送料时间已设置并验证硬停止；上方交接点到喷嘴的挤出机距离经过至少三次重复测量。
- [ ] 单 ACE 未配置一级五通；多 ACE 已完成分支清空方案。
- [ ] 切刀、擦嘴、停车和恢复坐标来自本机测量，不是示例值。
- [ ] 每个动作的归零条件、坐标模式、速度和安全间隙均已确认。
- [ ] 喷嘴温度与所用耗材匹配，挤出机允许挤出。
- [ ] 七个必用宏已逐项检查，故障暂停路径可用。
- [ ] 编码器保护仍保持关闭，或已完成本机校准和监测验收。
- [ ] 先单独验证一项动作，不使用完整多色打印任务作为首次测试。

完成检查只表示可以开始受控验收，不表示整套自动换料已经真机验证。每项物理动作都应单独记录结果；任一条件改变后重新检查。
