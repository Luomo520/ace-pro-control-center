## ACE-P0-001：安装事务与首次基线

### 目标

任何归档、安装、回滚或卸载步骤失败，都不能使原目标缺失；完整卸载在任意安装顺序下恢复项目第一次写入前状态。

### 必须完成

- 归档改为先复制、验证完整性，再移动或替换目标；不能在归档副本成功前声明目标存在于归档。
- 恢复失败必须向上传播并报告原路径、归档和隔离目录，不得用 `|| true` 隐藏。
- 安装、回滚、卸载和信号退出共享明确事务状态。
- 建立全局首次写入前基线，同时保留可解释的分组件状态。
- 覆盖 `driver -> all -> uninstall all`、`card -> all -> uninstall all`、`driver -> card -> uninstall all` 和反向顺序。

### 验收

- 故障注入后所有原路径的文件类型、内容和哈希不变。
- 三份基础安装器测试、事务故障注入测试和混合基线测试已在 Windows Git Bash 通过；原生 Linux 真实软链接场景仍需单独验证。
- 不连接打印机，不依赖服务重启。

## ACE-P0-003：驱动物理动作安全

状态：驱动、Moonraker、Fluidd 和备用页契约已同步，Python 139 项与 Web 27 项通过；尚未真机验证。

### 目标

维护动作、断联恢复和打印中失败遵守统一确认、互斥、暂停和不确定动作规则。

### 必须完成

- `ACE_CHANGE_SPOOL` 要求 `CONFIRM=1`，禁止打印/暂停期间执行，并进入运动互斥；当前槽完整卸载后不得二次回抽。
- 无五通传感器且停放回抽状态不确定时，不自动重放完整回抽，也不自动继续打印。
- 打印中切刀失败、传感器矛盾、普通回抽异常统一保持 `PAUSE`，空闲时只报错。
- 失败后停止送料辅助、释放互斥并保存明确阶段和位置诊断。

### 验收

- 新增换卷、无五通断联恢复、切刀失败、传感器矛盾和回抽失败测试。
- 测试证明没有重复切刀、重复不确定送料/回抽或错误自动 `RESUME`。
- 不执行真机物理动作。
