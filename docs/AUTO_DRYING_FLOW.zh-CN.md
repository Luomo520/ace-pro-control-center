# 自动跟随打印烘干流程

本流程由 ACEPROSV08 Klipper 驱动每秒读取 `print_stats` 执行，不依赖 Fluidd 页面保持打开，也不依赖切片器开始或结束宏。

```mermaid
flowchart TD
    A["每秒读取 print_stats"] --> B{"连续两次为 printing?"}
    B -- "否" --> C{"paused 或已在打印任务中?"}
    B -- "是" --> D["建立本次自动烘干任务"]
    C -- "paused" --> E["保持当前自动烘干"]
    C -- "完成 / 取消 / 错误 / 待机" --> F{"烘干是否由自动功能启动?"}
    F -- "是" --> G["停止自动烘干"]
    F -- "否，属于手动烘干" --> H["保持手动任务不变"]
    D --> I{"自动跟随打印已开启?"}
    I -- "否" --> J["仅显示状态，不启动"]
    I -- "是" --> K{"ACE 已连接且有已装载耗材?"}
    K -- "否" --> L["中文提示；连接恢复后重试，不影响打印"]
    K -- "是" --> M{"材料组合"}
    M -- "全部 PLA" --> N["45°C"]
    M -- "PLA 与其他材料混装" --> O["50°C，提示其他材料效果受限"]
    M -- "存在未知材料" --> P["45°C，提示烘干效果可能受限"]
    M -- "全为高温材料" --> Q["60°C，且不超过配置上限"]
    N --> R["启动 1440 分钟自动烘干"]
    O --> R
    P --> R
    Q --> R
    R --> S{"打印中库存变化?"}
    S -- "需要更低温度" --> T["停止后以更低温度重启"]
    S -- "可提高温度" --> U["本次打印不升温"]
    S -- "手动停止" --> V["本次打印禁止自动重启"]
    S -- "1440 分钟到期且仍在打印" --> W["按本次温度上限续期"]
    S -- "所有槽位变为空" --> X["停止自动烘干"]
```

## 温度优先级

1. 存在未知材料：`45°C`。
2. PLA 与其他已识别材料混装：`50°C`。
3. 全部为 PLA：`45°C`。
4. 全部为 ABS、ABSCF、PETG、PAHTCF、PETCF 或 PEEK：`60°C`。
5. 所有槽位为空：不启动烘干。

自动功能只停止自己启动的烘干。打印前手动开启的烘干不会被接管；打印中手动停止自动烘干后，本次打印不会再次自动启动。

启动、停止或 USB 断联造成的未确认请求使用 30 秒退避，同一任务最多尝试三次。打印结束时若启动请求仍在等待响应，驱动会记录“必须停止”；启动响应稍后成功时会立即发送停止命令。停止失败前不会提前清除自动任务所有权。
