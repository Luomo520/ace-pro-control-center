## 实施要求

1. 先读取 `AGENTS.md` 和 `docs/PROJECT_MEMORY.zh-CN.md`。
2. 列出代码证据和当前行为，不根据历史对话猜测。
3. 修改前说明文件、接口和行为影响。
4. 多智能体协作时保持写入文件互斥。
5. 打印机写入前后按上级 `AGENTS.md` 创建备份。
