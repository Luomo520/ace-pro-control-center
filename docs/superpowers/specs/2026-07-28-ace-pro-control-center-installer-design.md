# Ace Pro Control Center 安装器升级设计

## 目标

将当前安装器升级为 Ace Pro Control Center / ACE Pro 管理中心的一体化安装器。项目源自 ACEPROSV08，但作为独立项目维护，不再把 ACEPROSV08 或其他 ACE 驱动视为需要检测、迁移或清理的外部依赖。

安装器必须提供双语字符界面、五通传感器配置向导、Fluidd 与 Moonraker 版本风险提示，以及可恢复的安装、回滚和卸载流程。

## 项目身份与兼容边界

用户选择简体中文时，项目显示名称为 `ACE Pro 管理中心`；选择英文时，项目显示名称为 `Ace Pro Control Center`。

内部安装路径不随语言变化：

```text
~/ace-pro-control-center
~/.local/share/ace-pro-control-center
```

安装标记、归档清单和内部状态字段统一使用稳定标识 `ace-pro-control-center`。用户可见的标题、菜单、提示、错误、日志摘要和教程入口根据语言显示对应项目名称。

`ace` 是设备和通信协议名称，以下运行时兼容标识保持不变：

```text
[ace]
ACE_*
/server/ace/...
ace.cfg
ace.py
ace_status.py
```

项目来源和许可证在 README 与安装教程中注明，但安装器不使用来源项目名称作为当前项目名称。

## 语言选择

交互式安装器启动后首先显示语言选择：

```text
1. 简体中文
2. English
```

默认项根据 `LANG`、`LC_ALL` 或 `LC_MESSAGES` 判断；中文环境默认简体中文，其他环境默认英文。用户可以手动覆盖。

命令行和自动化场景支持环境变量 `ACE_CC_LANG=zh-CN|en-US`。非交互环境未指定语言时采用系统检测结果，不因无法读取语言而中断安装。

语言选择影响安装器显示内容，不改变安装路径、配置字段、API 或 G-code 命令。

## 安装菜单

字符菜单提供以下功能：

1. 安装或更新完整组件，默认包含驱动、Moonraker 组件和 Fluidd 卡片。
2. 仅安装或更新驱动。
3. 仅安装或更新 Fluidd 卡片和 Moonraker 组件。
4. 强制安装完整组件，跳过允许跳过的兼容性检查，但仍执行文件校验和备份。
5. 回滚最近一次安装。
6. 卸载并恢复首次安装前状态。
7. 检查当前状态。
8. 退出。

完整安装和驱动安装默认保留现有 `ace.cfg`。如果目标配置不存在，则根据模板和安装向导生成新配置。用户可以明确选择使用新版配置替换现有配置，替换前必须归档旧配置。

## 全新驱动安装策略

安装器不检测、不识别、不迁移、不卸载 Kobra-S1/ACEPRO、ACEPROSV08 或其他类型的 ACE 驱动。

安装前仅检查本项目需要写入的目标路径和文件是否存在。目标文件已存在时，统一提示这些文件会先进入归档，不判断其来源或类型。

安装器不会主动搜索其他驱动字段，也不会基于其他驱动的配置决定本项目安装行为。用户自行负责在安装前移除不再使用的冲突 include；状态检查只报告本项目目标文件和配置是否完整。

## 五通传感器向导

完整安装和驱动安装时询问是否使用五通传感器：

```text
1. 已安装五通传感器
2. 未安装五通传感器
3. 暂不配置，安装后手动填写
```

选择已安装后继续询问：

- MCU 引脚。允许留空，留空时不启用传感器。
- 安装位置，默认 `after_five_way`，也可选择 `before_five_way`。

配置生成规则：

- 已填写引脚时生成 `parking_sensor_pin: <输入值>`。
- 未安装或引脚留空时保持 `parking_sensor_pin` 注释。
- 安装位置始终写入有效的 `parking_sensor_position`。
- 不猜测、不复用、不预填任何真实 MCU 引脚。
- 对引脚只做语法级字符检查，不连接 MCU，也不触发任何物理动作。

存在用户 `ace.cfg` 且选择保留配置时，安装器不修改活动配置。向导结果写入新的 `ace.cfg.example`，并在安装摘要中提示活动配置仍需用户自行调整。

命令行场景支持：

```text
ACE_CC_PARKING_SENSOR=yes|no|later
ACE_CC_PARKING_SENSOR_PIN=<pin>
ACE_CC_PARKING_SENSOR_POSITION=after_five_way|before_five_way
ACE_CC_CONFIG_MODE=preserve|replace
```

非交互环境未提供五通参数时采用 `later`，保持引脚注释，确保不会因错误默认值引发硬件动作。

## Fluidd 与 Moonraker 兼容性

安装器顶部显示当前 Fluidd、Moonraker、驱动和安装包版本，以及兼容性状态。

Fluidd 版本依次从 `.version`、可用的构建元数据和页面元数据读取。Moonraker 版本依次从 `.version`、Git 描述和本机 `/server/info` API 读取。所有检测失败时显示“未知”，不伪造版本。

当前打包的 Fluidd 构建版本作为测试基准。版本一致时正常安装；版本较低、较高或未知时显示具体风险。Moonraker 版本未知或不在已验证范围时提示组件 API 可能不兼容。

完整安装遇到兼容性风险时提供：

1. 仅安装驱动，跳过 Fluidd 卡片和 Moonraker 组件。
2. 继续安装完整组件，并确认了解兼容与回滚风险。
3. 取消安装。

仅安装卡片时遇到风险必须二次确认。强制安装可以跳过版本阻断，但不能跳过备份、发布文件校验或安装失败恢复。

高版本 Fluidd 不会被静默替换；提示必须明确说明继续后可能被替换为安装包内的测试版本。安装器不宣称未验证版本完全兼容。

## 安装事务与归档

每次实际写入前创建唯一时间戳归档，不覆盖或删除历史归档。归档至少包含：

- 当前 Fluidd 目录或本次涉及的完整前端文件。
- Moonraker ACE 组件和 Moonraker 配置。
- ACE 驱动文件、软链接及链接目标。
- `ace.cfg`、`ace.cfg.example` 和 `printer.cfg`。
- 本项目安装状态文件。
- 安装前版本、安装范围、语言、配置模式和五通传感器选择。
- 文件存在性、目标路径和 SHA-256 校验结果。

安装文件先写入临时路径，完成基本校验后再替换目标。任何步骤失败时停止后续写入并从本次归档恢复；恢复失败时保留现场并报告具体路径，不宣称安装成功。

首次成功安装时记录首次安装前基线，后续更新不覆盖该基线。

## 回滚与卸载

回滚最近安装前先归档当前状态，然后恢复最近一次安装前的文件。回滚失败时尝试恢复回滚前状态，并保留两个归档供人工检查。

卸载优先恢复首次安装前基线。首次安装前不存在的目标文件只删除本安装器明确创建且仍由安装状态清单跟踪的文件。卸载不删除用户后来创建的配置、不删除历史归档，也不处理任何其他 ACE 驱动。

卸载驱动、仅卸载卡片等命令行范围继续保留，并遵循对应范围的基线和状态清单。

## 状态检查

状态检查只读，不创建备份，也不修改服务。输出包括：

- 项目名称与安装语言。
- 安装包和已安装版本。
- Fluidd 与 Moonraker 当前版本。
- 驱动、Moonraker 组件、Fluidd 卡片和配置文件是否存在。
- 五通传感器配置是启用、未启用还是需要填写引脚。
- 最近归档和首次安装前基线。
- 已检测到的兼容性风险。

## 测试与验收

安装器测试覆盖：

- 中英文菜单、提示和项目名称。
- 系统语言自动选择与环境变量覆盖。
- 全新安装不扫描其他类型驱动。
- 无五通传感器、填写引脚、留空稍后配置和两种传感器位置。
- 已有 `ace.cfg` 时保留配置，明确替换时使用新配置。
- Fluidd 和 Moonraker 的匹配、较低、较高和未知版本。
- 版本风险下仅安装驱动、继续完整安装和取消。
- 强制安装仍执行备份和校验。
- 安装失败自动恢复。
- 最近安装回滚。
- 完整卸载、范围卸载和首次安装前状态恢复。
- 旧归档、用户配置及无关文件不会被删除。
- POSIX shell 语法、发布清单校验和现有安装器测试全部通过。

本次实现只修改本地项目文件，不连接打印机、不触发硬件动作、不提交或上传 GitHub。
