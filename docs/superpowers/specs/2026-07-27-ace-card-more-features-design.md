# ACE Pro 卡片“更多功能”折叠设计

## 目标

缩短 Fluidd 仪表板中的 ACE Pro 卡片。料槽管理下方的“距离标定与预装载”、
“手动送料”和“快捷操作”三个区域整体收进一个“更多功能”折叠栏，默认收起。

## 作用范围

- 仅 Fluidd 仪表板中的 ACE Pro 卡片默认收起更多功能。
- 独立的 Fluidd `#/acepro` 页面保持三个区域直接展开，便于集中操作。
- `/ace.html` 保持现有完整布局。
- 不修改 ACEPROSV08 驱动、Moonraker API、命令参数、确认弹窗或安全限制。

## 交互与布局

- 在料槽管理后显示一行全宽的“更多功能”按钮和展开状态箭头。
- 仪表板首次渲染或重新加载时默认收起，不持久化上次展开状态。
- 点击按钮一次展开三个区域，再次点击收起。
- 展开和收起使用 Fluidd 已有的 `v-expand-transition`，不改变内部控件状态和命令处理。
- 按钮使用真实 `button` 语义、明确的 `aria-expanded` 状态和足够的点击区域。
- 桌面与窄屏均保持一行标题，展开内容沿用现有响应式布局。

## 组件边界

`AceProCard` 新增显式布尔属性控制是否允许折叠更多功能。Dashboard 使用默认折叠模式，
专用 `AcePro` 页面显式关闭折叠。折叠状态只属于组件实例，不进入 Vuex，也不影响实时
状态轮询。

## 验证

- 先添加合同测试，要求存在“更多功能”、展开状态和三个区域的统一折叠容器，并确认
  专用页面显式保持展开。
- 运行 Web 合同测试、Fluidd 单元测试、类型检查、Lint 和生产构建。
- 在桌面与窄屏视口验证仪表板默认高度明显缩短，展开后功能完整且没有重叠。
- 部署前后遵守打印机备份规则；部署验证不触发送料、回抽、切刀、换料或标定。
