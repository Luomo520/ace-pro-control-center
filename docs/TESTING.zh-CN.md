# Ace Pro Control Center | ACE Pro 管理中心：第三代测试门槛

## 1. 单元测试

- ACE1 帧头、长度、CRC、请求 ID、分包和异常响应。
- ACE2 解码、UID、能力声明和只读门禁。
- 配置数量、连续设备名、型号、串口重复和 `bus_id` 校验。
- 单文件配置解析：`ace.cfg` 同时包含 `[ace_hardware]`、`[ace_device ace0..ace3]`、`[ace]`、`[ace_machine]` 和宏时，所有配置节保持原有语义；活动配置不得依赖 `ace_hardware.cfg` 或 `ace_machine.cfg` include。
- `ace0..ace3` 到 `T0..T15` 的稳定映射。
- 固定注册 `T0..T15/TR`；单 ACE 手动模式遇到超出已配置范围的 T 指令仍提示后继续。
- 每实例队列、定时器、缓存和错误状态互不污染。
- 当前工具、路径锁、无限续料和持久化恢复。
- V2 单机/多设备库存只迁移一次，已有 V3 库存优先。
- RFID 识别失败的空材料/黑色占位值不得覆盖用户库存；已识别的真实黑色耗材仍保持黑色。
- `rfid_enabled` 默认开启、可按设备独立关闭；关闭时硬件 RFID 元数据不得覆盖手工库存。
- 槽位 RFID 数值仍按协议解析，但界面将 `0/1` 统一显示为“已关闭”，将 `2/3` 分别显示为“已识别/识别中”。
- 总五通单独使用 `rdm_sensor_debounce_count`；只有 2 至 4 台 ACE 才创建一级五通对象并使用 `ace_hub_sensor_debounce_count`。
- 新模板的上方、下方、总五通、一级五通和共享编码器只包含 `*_sensor_pin`：空 pin 禁用，有值时使用固定内部名称创建对象；所有 `*_sensor_name` 只覆盖旧配置解析与升级兼容，不得重新写回用户模板。下方 pin 为空必须仍可通过自动换料传感器就绪检查。
- 入口到喷嘴的挤出机标定距离默认样板为 `25 mm`，用户必须按本机实测修改；显式填写 `0` 不得导致 Klipper 配置加载失败，但必须阻止自动换料。测试必须把该挤出机距离与 ACE 的固件参考距离分开，任何 ACE 命令距离或累计值都不得成为耗材位置或送料成功判据。
- 共享编码器配置覆盖空引脚禁用、有效引脚创建固定内部对象、ACE 动作默认 `off` 与 `monitor/protect` 枚举、打印监测默认 `off` 与 `monitor/pause` 枚举、两套检测距离边界及旧显式 name 兼容。
- 七个 `[ace_machine]` 绑定默认全部启用并标记 `!!!【必用】`；换料前处理、切刀、擦嘴和换料后处理的物理实现样板保持整段注释。逐项缺失任一实现时自动换料必须未就绪，但 Klipper、手动模式和已授权的 ACE 内置辅助送料仍可用。

## 2. 集成测试

- 单 ACE1 模拟串口：识别、刷新、烘干、送丝、回抽、装载、卸载和换料。
- 断线、超时、未知响应、设备重启和重复请求。
- Reactor 在串口超时期间仍可调度；非幂等物理命令超时后不重发。
- 送料、回抽必须等待 ready；七个必用宏的任一预检失败时串口不得出现物理请求。
- 1-4 台 ACE1 并行轮询，验证物理路径动作串行化。
- ACE1+ACE2、ACE2+ACE2 配置解析和状态展示。
- ACE2 的送丝、回抽、换料、助推和烘干均被拒绝。
- 安装器全新安装只生成 `ace.cfg`，并确保 `printer.cfg` 的 ACE 相关配置只有 `[include ace.cfg]`；重复安装不得创建第二份活动硬件或机器配置。
- 旧 `ace_hardware.cfg` 只迁移一次：合并值后移除旧 include，将原文件以不覆盖历史的名称归档到 `.ace-driver-v3/legacy/`，后续重装不得从归档反向覆盖 `ace.cfg`。旧 `ace_machine.cfg` 同样不得留在运行链。
- 增删或换序设备时，安装器按稳定串口身份或 ACE2 总线与 UID 保留 `enabled`、`rfid_enabled` 和 `physical_actions_enabled`；新设备不得继承已移除设备的物理动作授权。
- 升级事务失败必须同时恢复 `ace.cfg`、`printer.cfg` include 和迁移文件位置；卸载保留 `ace.cfg` 与 `.ace-driver-v3/legacy/`。
- 五通测试覆盖单 ACE 不创建一级五通对象，以及多 ACE 的全部传感器、仅总五通、一级传感器空引脚、每设备独立盲回退和跨设备清空顺序。
- ACE 寻位测试必须证明上方传感器稳定触发是唯一送料成功终点；不同 ACE 固件参考距离不会改变这一结论；预设参考量耗尽后仍在总超时内继续受限分段；固件提前返回完成仍等待传感器宽限；迟到触发不能反转超时；编码器持续有脉冲也不能越过最大送料时间；超时、传感器故障和 ACE 状态未知均停止送料且不得标记已装载。
- 下方传感器测试必须覆盖无引脚和有引脚两种配置：默认 `toolhead_sensor_bypass: True` 时原始状态持续上报但不参与五类判定；用户显式设为 `False` 时恢复下方闭环，并要求有效引脚、距离及触发/释放验证。下方传感器不是通用安装必需项。
- 入口到喷嘴标定距离为 `0` 或缺失时不得发送 ACE、挤出机、切刀或机器宏物理动作，Klipper、只读状态、手动模式和已授权的辅助送料仍保持可用，并提供明确的自动换料未就绪原因。负数和非有限值必须由配置解析拒绝，运行时注入异常值也必须在物理动作前被 readiness 拒绝。
- 编码器覆盖默认 `150 mm`、默认 `3` 段的人工校准，每段独立脉冲数与 `mm/脉冲`、`<=5%` 直接通过、`>5%` 且 `<=10%` 警告确认后保存、`>10%` 拒绝、任一段脉冲不足拒绝、主动取消、重复开始拒绝、打印中校准动作拒绝及校准期间动作门禁。还必须覆盖运行时短检测窗口边界、ACE 寻位段和挤出机接管段的 `monitor` 只记录、`protect` 中止并禁止标记已装载，以及未校准时自动换料未就绪；任何模式都不得把 `150 mm` 校准段当成运行时等待距离或无上限追加送料。
- 打印监测覆盖物理挤出位置采样、`G92 E0` 无影响、净挤出累计、回抽/恢复抵消、路径未装载或事务中不活动、新脉冲重置余量、达到阈值单事件、`monitor` 继续打印、`pause` 仅请求一次暂停，以及故障现场和可能原因结构。

## 3. 拓扑测试

- `/dev/serial/by-id` 路径优先于短设备名。
- USB 重枚举不改变 `ace0` 的逻辑身份。
- USB `LOCATION` 变化只产生诊断或配置错误，不自动换绑。
- ACE2 同一共享总线只允许在明确配置的设备之间复用。
- ACE2 UID 丢失、重复或变化时保持离线，不接管其他实例。
- ACE2 `device_uid: auto` 在具备持久化发现流程前必须由配置校验拒绝。

## 4. 用户界面测试

- 当前设备保持 V2 管理顺序：状态、烘干、四槽、手动送料和快捷操作。
- 单 ACE 隐藏设备切换；多 ACE 显示连续的 ACE1-ACE4 按钮，切换后四槽工具编号和动作目标同步更新。
- Fluidd 原生工具命令区按 `ace.device_count` 显示 4/8/12/16 个按钮，每台设备独占一行四列；单 ACE 不得出现 `T4-T15`，ACE 状态缺失时必须保持上游分组。
- 未配置、离线、只读、动作中和失败状态可区分。
- 桌面和移动宽度无文字溢出、按钮重排错误或卡片重叠。
- API 失败不会回退为直接执行原始 G-code。
- Fluidd 卡片与独立控制界面使用相同工具、库存、能力和阻塞原因。
- 手动/未就绪状态逐条消费工具提示队列；首次加载完整消费当前队列，Klipper 通知序号重置后不得漏掉第一条，连续 T 指令不合并。
- 自动换料测试必须覆盖 `M82`、`M83` 和直接 E 移动失败路径，证明换料前后的逻辑 E 坐标与挤出模式不变；冷挤出或单次移动超过 `max_extrude_only_distance` 时必须在 ACE 物理动作前失败。
- 辅助送料全局单槽；打印中启用需要确认且最终 G-code 必须包含 `CONFIRM=1`，停用不需要确认且可释放繁忙路径；自动装载前先停用活动槽位。
- 独立界面覆盖换料、库存、维护、烘干、无限续料、诊断和恢复；通用机器动作校准保持禁用，共享编码器向导覆盖开始、实测长度校验、完成、取消、打印中禁用和无自动电机动作。卡片与独立页均覆盖打印监测状态、检测余量、故障现场和按事件序号去重的提示。
- Fluidd 状态必须把下方传感器显示为可选原始状态，不得使用“闭环已恢复”或“缺失导致降级”等文案；入口到喷嘴标定距离无效时显示自动换料未就绪，但不能归因于下方传感器。
- 网络重试、页面刷新和浏览器恢复不会重复提交物理动作。
- “刷新耗材数据”调用硬件刷新动作；普通定时刷新只读取缓存。
- 手动送料和回抽必须选择槽位；设备面板不得出现会操作其他设备当前工具的卸载按钮。

## 5. 真机门槛

真机测试顺序固定为：识别、只读轮询、刷新、上方/五通传感器电平、可选下方传感器显示、共享编码器脉冲、默认三段 `150 mm` 人工校准与取消、段间一致性阈值、ACE 寻位短窗口 `monitor` 观测、挤出机接管短窗口 `monitor` 观测、打印短窗口 `monitor` 观测、烘干、上方传感器触发停止、入口到喷嘴距离重复标定、回抽至上方释放、ACE 清空五通、ACE `protect` 故障路径、打印 `pause` 故障路径、完整换料和断线恢复。ACE1 完成前不得测试多设备物理并发。ACE2 只有协议模拟和只读边界，没有实体设备时不得进入任何物理动作验收。

本地测试通过不等于真机动作通过。每项真机测试必须记录设备型号、配置、日志、结果和是否发生物理动作。

两级五通在本地通过模拟测试不代表五个真实五通的传感器位置、回退距离或跨设备清空已经验证。共享编码器模拟脉冲也不代表真实引脚、电平、分辨率和打滑响应已经验证；单元测试也不代表上方传感器到喷嘴的挤出机标定距离、最大送料时间或上方触发停止已经安全。未完成相应真机步骤时必须保持自动换料、`encoder_mode: protect` 和 `encoder_print_mode: pause` 关闭。
